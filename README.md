# CAMEL JAPAN — Development preview

自社ホームページの開発プレビューです。GitHub Pagesでmainブランチのルートを公開します。

- 社内ポータルの物件掲載管理から、公開対象の物件情報・写真をlistings/へ反映します。
- 社内メモ、掲載元資料、許諾根拠、認証情報は公開しません。
- 掲載期限を過ぎた物件はサイトの表示対象から外れます。
- アットホーム・SNSへの自動配信は未接続です。
- このリポジトリにはビルド済みの公開ファイルのみを置きます。
- フロントエンド更新時は、公開済みのlistings/を維持してください。
- 開発中のためnoindexです。
