# CAMEL JAPAN — Development preview

GitHub Pagesで公開するホームページの開発プレビューです。

- 公開ファイル: HTML / CSS / JavaScript / 写真
- 公開元: main ブランチのルート（GitHub Pages）
- デザイン・アニメーション・目的選択・会社案内を確認できます。
- 物件情報の自動連携は未接続です。「掲載準備中」と表示されます。
- 開発中のため検索エンジン向けに noindex を指定しています。

このリポジトリはビルド済み公開ファイルを管理します。元のReact/TypeScriptソースは制作環境で管理し、静的ビルドを更新して反映します。APIキー・ログイン情報は含めません。
